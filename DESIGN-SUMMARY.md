# Design summary

- Design concept: Queue command center
- Layout personality: full-width layered panels
- Typography: Barlow Condensed headings with Atkinson Hyperlegible body text
- Color palette: primary #0f172a, secondary #38bdf8, accent #f43f5e, background #e0f2fe, text #0f172a, muted #64748b
- Shape language: Slight rounding
- Visual motif: ticket lanes and live queue bars
- Unique layout choices: first sections use Coverage board, then a custom service index, process ribbon, question block, and resource strip with varied widths and alignments.
- Difference from previous sites: this redesign changes the hero composition, section ordering, image treatment, card style, spacing rhythm, button shape, and footer treatment for this domain.
